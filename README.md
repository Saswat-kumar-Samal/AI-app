# AI-app
this is the AI app where you can generate article , create Images, review resume and many more


tech stack

in frontend
-----------

react-router-dom -> for navigating router

lucide-react -> for using icon 
react-markdown -> for organizing data


in backend
----------

express -> for backend framework
dotenv -> for environment variable
axios -> for API handling
cloudinary - cloud storage of images 
multer -> uploading images using multer (to cloud)
cors -> to connect backend to any frontend


third-party application
------------------------

clerk -> for authentication
neon.com -> for database
clipdrop -> for generating images
cloudinary - cloud storage of images
